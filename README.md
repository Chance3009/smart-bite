# Smart Bite

## Overview
This project provides a comprehensive solution for meal planning, calorie tracking, and personalized diet recommendations. The application has a Flutter-based frontend and a Python-based backend using Flask.

## Directories
- **frontend/**: Contains the Flutter app for user interactions.
- **backend/**:  Contains the Python Flask server for processing and handling requests, along with machine learning models for analysis.
